# Accept pre-computed embeddings directly

## Problem

Users who already have embeddings stored in a database or generated by external pipelines must re-download images and re-embed them through headmaster's embed step. This adds friction and couples headmaster to specific infra.

## Approach

Allow `hm train` to accept pre-computed vectors directly (e.g. numpy `.npy`/`.npz` or parquet files), skipping the image download + re-embed step entirely. This makes headmaster generalizable to anyone with embeddings in any format.
